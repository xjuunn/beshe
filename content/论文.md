# 基于Web的校园百货零售网站设计与实现

----

## 1 绪论

### 1.1 研究背景与意义

从用户角度出发，电子商务在年轻群体中快速普及，而校园零售的传统模式已经显得落后，效率低、体验差，无法满足学生对快速浏览、便捷支付和高效配送的期望。通过本课题的研究与实现，校园用户可以轻松地浏览商品、管理购物车、完成订单支付，从而提升校园用户地购物体验。

从管理角度看，零售管理地效率决定了服务质量，一个没有数据驱动、流程混乱的管理后台，只会让运营者手忙脚乱。这时候，一个具有商品分类、库存监控、订单处理和销售统计功能的后台管理系统显得尤为重要。对数据统计分析同时，管理者还可以深入了解消费趋势，帮助管理者实现精细化运营，为未来的优化和决策提供可靠依据。

更重要的是，在数字化浪潮的今天，智慧校园的概念已经被越来越多的高校接受，而零售的数字化转型是智慧校园不可或缺的一环。通过使用Vue3和Spring Boot这些技术，不仅在技术上保持先进性，还为系统的扩展性和性能提供了坚实保障。

技术的价值在于解决问题，创新的核心是服务用户。总之，本课题通过构建一个功能完善、操作简便的校园百货零售网站，满足用户多样性的需求，提升零售管理效率，推动校园零售数字化和智能化的发展。这将为高效师生的日常生活提供便利，并为校园经济建设做出积极贡献。



### 1.2 国内外研究现状

在过去的几年里，电商行业的发展已经不再局限于传统的大型平台，它已经擅入到每个行业，每个生活场景中。尤其是在校园零售这个领域，随着大学生消费需求的多样化和技术的进步，市场规模越来越大，而通过Web技术构建的校园百货零售平台，正是一个非常具备潜力的平台。从或内外的现状来看，校园零售电商正处于迅速发展的阶段，并逐渐趋向于多元化和智能化。

在国内，校园电商的快速崛起得到了多方关注。近年来，饿了么发布了“数字校园生态联盟计划”，宣布全面升级“智慧校园”数字化服务，进而推动校园即时电商市场的发展。根据饿了么发布的数据，过去一年来自高校的订单已经突破了10亿单，校园用户订单增长速度超过整体外卖用户的平均增速。尤其是在“后疫情时期”，校园消费需求迅速增长，学生对外卖的需求已经不再仅限于餐饮，甚至涵盖了零售、美妆、娱乐等多元化领域。这一变化反映出，校园消费市场规模已经达到了“万亿”级别，市场增量空间巨大。由此，数字化服务的全面升级和校园电商平台的进一步发展，已经成为提升学生生活品质的重要因素。

此外，天猫也在高校市场深耕，推出了全国首个天猫校园店，在四川师范大学开设了新的零售实体店。并通过大数据分析精准匹配商品和用户需求，从而提升了商业运营的效率。根据天猫的计划，未来将继续扩展校园零售店铺，计划在三年内进驻全国1000所高校，服务超2000万高校人群。

国外关于基于Web的零售网站发展，正处于快速变化和创新的关键阶段，在用户功能方面，个性化推荐、智能搜索和便捷支付已经成为标配，国外很多企业通过不断地技术迭代，成为行业地标杆。在欧洲，电子支付地普及率较高，一些校园平台还集成了校园内地支付系统，使结算更加方便。个性化推荐和智能搜索技术正在快速发展，例如亚马逊等公司采用机器学习算法来提高用户地搜索体验和推荐精度。

电子商务的未来发展趋势表明，个性化服务和数据驱动的运营将成为零售行业的重要方向。本课题的研究通过提供用户评价和反馈功能，不仅能帮助管理者更好的优化服务，还能增强用户的参与感和粘性。此外数据统计分析功能为零售管理者提供了更精准的决策支持。通过提升用户和管理者的满意度有助于构建健康发展的校园经济生态，增强校园经济的活力和可持续性。

## 2 系统需求分析

### 2.1 系统功能需求

该系统采用前后端分离架构，前端使用Vue3构建用户界面，后端使用Spring Boot处理业务逻辑，并通过RESTful API进行数据交互。数据库采用MySQL。系统旨在为校园师生提供便捷的购物体验，同时为管理员提供高效的商品和订单管理工具。

1.   响应式布局：用户和管理员可以在PC端或移动端访问网站，适配不同分辨率的设备，均能获得良好的跨设备体验。
2.   账户管理：支持用户的注册、登录操作，对用户的密码进行加密保存，保证账号的安全和用户的隐私。
3.   商品管理：提供商品的添加、删除、修改、分类、库存监控的功能。使管理员便捷的管理和监控商品的状态，保证系统的稳定运行和商品的正常运营。
4.   购物：用户可以浏览商品，通过分类或者关键词搜索想要的商品，用户可以查看商品的详细信息，选择购买数量，加入购物车，购买支付等操作，保证用户的便捷性。
5.   订单管理：用户可以创建订单，管理员可以对订单进行管理，包括订单的删除，订单状态更新等操作。
6.   评价与反馈：购买商品的用户可以对这个商品进行评价，管理员可以管理评价信息，可以删除用户的评价。
7.   数据统计分析：系统自动统计销售数据，生成报表供管理员查看。
8.   安全性：采用身份认证、数据加密、权限管理等措施，无权限的用户无法访问后台页面，用户密码加密存储，未登录用户无法购买商品，用户登录后，过一段时间需要重新登录等，确保系统的安全稳定运行。

### 2.2 用户需求分析

普通消费者主要使用前台功能，设计商品的浏览、支付、订单管理等。

用户可以在主页浏览商品，或者通过关键词搜索商品信息，也可以通过商品分类搜索商品，支持模糊搜索，快速找到目标商品。商品详情页面提供商品的描述、型号、价格、用户评价等信息；用户可以将商品添加到购物车，并可以调整购买数量或移除商品。购物车显示商品的信息、总价格等；用户可以查看和修改个人信息、修改手机号、收货地址等。购买商品后，自动以用户信息的收货地址作为发货地址，支付成功后可以在订单列表查看；用户可以对购买的商品进行评价，包括评分、文字评价等。用户可以查看其他人的评价，了解商品质量。



### 2.3 后台管理员需求分析

后台管理员主要负责管理商品、库存、订单、用户等，确保系统正常的运行。

管理员可以在仪表盘查看系统的总体状态，如在线人数、商品种类和重要通知等功能；查看本月的销量和收入；查看最新的用户评价；低库存的商品列表；商品销量排行和受欢迎商品种类的分析等重要信息，便于管理员快速了解当前的系统运行状态和商品状态等信息，便于管理员快速定位信息，以便及时做出响应。

管理员可以在用户列表页面查看和管理普通用户信息，通过手机号，邮箱和用户名搜索用户。

管理员可以在评价反馈页面查看所有的评论信息，还可以对评论进行删除；

管理员可以在商品列表页面查看所有的商品，分页显示，可以通过商品名查询商品，点击新增商品按钮可以新增商品，可以修改和删除和修改商品信息。

管理员可以在商品分页页面管理所有的商品分类，并通过一定顺序进行排序，管理员可以修改商品分类的顺序，可以新增商品分类，修改商品分类的分类名称和顺序，也可以删除商品分类。

管理员可以在库存警告页面可以查看所有的库存不足的商品，以便管理员快速定位哪些商品库存不足，快速补货。

管理员可以在订单列表页面查看所有用户订单，分页显示，管理员可以查看订单详情，商品详情，用户详情，也可以删除订单。

管理员可以在退款和售后页面查看所有的退款和退货订单，管理员可以对订单给予驳回和通过操作。

## 3 系统开发技术介绍

### 3.1 Vue3框架

Vue3框架是国内最受欢迎的前端框架之一，Vue的核心是响应式数据绑定和组件加开发，它具有易学易用、性能出色、适用场景丰富的Web框架。它基于标准的HTML、CSS、JavaScript构建，并基于组件的形式构建用户页面，简化了数据的管理和数据更新，提高了代码的复用性和可维护性，同时也具有非常好的性能。Vue具有良好的生态系统，功能覆盖了大部分的前端开发常见的需求，使前端系统更加高效，进一步提高了用户的体验，确保想哭具有更好的可维护性和可扩展性。



### 3.2 Spring Boot框架

Spring Boot作为Spring框架的一个快速开发解决方案，它简化了Spring应用的开发和部署，可以快速构建独立的、生产级的Spring应用，而无需繁琐的XML配置。Spring Boot结合了Spring生态系统的强大功能，适用于微服务架构、RESTful API开发、Web应用等多种场景。Spring Boot作为一个轻量级、高性能、易扩展的后端开发框架，并提供了一整套高效的解决方案，能够满足本项目的功能需求，并具备良好的可扩展性，为未来的维护和升级提供便利。



### 3.3 MySQL数据库

MySQL是一种流行的关系型数据库，它基于SQL进行数据库管理，具有高效性、可扩展、稳定、安全等特点，广泛应用于Web开发、电子商务、企业管理等领域。



###  3.4 前后端分离架构设计

本项目采用前后端分离的架构，即前端(Vue)和后端(Spring Boot)独立开发、独立部署，通过API进行通信。这种架构能够提高开发效率、提升系统的扩展性，并支持多终端适配。采用该架构后，前后端解耦，提高开发的效率和可维护性，使系统具备包性能、可扩展、易维护的特点。

本项目主要由以下三个部分组成:

1.   前端：用户界面，负责渲染和交互逻辑
2.   后端：提供API接口，负责业务逻辑处理，数据库操作等。
3.   数据库：存储业务数据，如用户、商品、订单等。

## 4 系统总体设计

### 4.1 前端系统架构设计

前端系统采用Vue3 + Nuxt3 进行开发，并结合Pinia、Axios、DaisyUI进行页面渲染、状态管理、API交互和UI框架支持。

技术选型：

| 技术        | 说明                                                         |
| ----------- | ------------------------------------------------------------ |
| Vue3        | 轻量级、响应式前端框架                                       |
| Nuxt3       | 快速开发框架，减少配置                                       |
| Vite        | 高速构建工具，提升开发效率                                   |
| Pinia       | 轻量级状态管理工具，替代Vuex，比Vuex更轻量，更简单，支持组合式API |
| Axios       | HTTP请求库，与后端交互                                       |
| TypeScript  | 提高代码的可读性和可维护性                                   |
| TailwindCSS | 原子化CSS框架，减少CSS代码冗余，提高开发效率                 |
| DaisyUI     | 基于TailwindCSS的UI组件库，提供丰富的主题和组件，提升UI设计美观度 |

本系统采用前后端分离架构，前端基于Vue3开发，整体架构如下：

*   页面层(pages)：`pages`目录用于自动路由，组织页面结构。
*   组件层(components)：拆分常用UI组件和业务组件，复用性强。
*   状态管理层(stores)：使用Pinia管理全局状态，保证数据共享。
*   API请求层(api)：封装API请求，对请求代码统一进行管理。
*   布局层(layouts)：前后台使用不同的布局。

采用文件系统路由，直接使用文件路径作为路由路径，支持动态路由。使用JWT进行用户身份验证，登录后token存储在Pinia和localStore，在守卫中拦截未登录和无权限用户，跳转到登录页面和无权限页面。使用TailwindCSS适配不同分辨率设备，在不同设备上都能看到舒适的用户界面。封装Axios，让每次请求携带token，并且在合适的时机刷新token。使用DaisyUI，所有的颜色均使用内置颜色，有利于实现主题的配置，以及实现深色模式和亮色模式切换的功能。

在前端系统中，使用ssr进行在线用户数量的统计和管理。

### 4.2 系统模块划分与功能概述

1.   用户管理模块：前台用户可以登录和注册、获取用户头像，查看自己的账号详情、修改自己的账号信息、上传头像；后台管理员可以删除用户、更新用户、分页查询所有用户列表、通过用户名，邮箱或者手机号搜索用户。
2.   商品管理模块：前台用户可以查看商品列表、查看商品详情、通过关键字或者分类搜索商品、查看商品图片；后台管理员可以新增和删除商品、更新商品信息和修改商品图片、查看库存过低的商品、修改商品库存量。
3.   购物车管理模块：前台用户可以添加商品到购物车、删除购物车、修改购物车商品数量、查看购物车列表。
4.   商品分类管理：前台用户可以获取所有的商品分类；后台管理员可以查看商品分类、修改商品分类、添加商品分类以及删除商品分类、修改商品分类排序字段等功能。
5.   订单管理模块：前台用户可以创建商品订单，查看自己的订单列表、查看订单详情、退货申请和取消订单功能；后台管理员可以查看所有用户的订单、删除订单、批准和驳回退货申请和退款申请。
6.   评价管理模块：前台用户可以对自己购买的商品进行评价、可以查看某个商品的评价列表；后台管理员可以查看所有的商品评价信息、删除某个评价、查看最新的几条评价。
7.   销售管理模块：前台用户可以创建自己的购买记录；后台管理员可以查看所有的销售记录、查看销售总额和销售数量、查看销售排行、查看本月销售额。
